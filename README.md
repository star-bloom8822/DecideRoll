# DecideRoll
A lightweight, responsive, offline website designed to eliminate choice fatigue and settle everyday decisions instantly.


## ✨ Features
*   **⚡ Instant Presets:** Pre-loaded lists for Dinner Options, Hobbies & Activities, and Movie Genres, along with a custom list option. 
*   **🚫 Rule-Out Mode:** Easily rule out items for the current session without deleting them permanently.
*   **🔊 Text-to-Speech:** Reads out your list or announces the final winning decision aloud. 
*   **🔀 Smart Text Tools:**Quick action buttons for undoing changes and shuffling list order.
*   **🎉 Delightful Animation:** Announces the winner with a custom internal confetti effect.
